阿克曼轉向機構理論分析

Ackermann Steering Geometry · MG90S Servo Front Steering

轉彎時內外前輪該轉多少度、這組伺服曲柄＋拉桿機構實際轉多少度，兩者差多少、為什麼這樣選尺寸。所有數字與圖都由轉向機構的連桿程式 linkage.py 直接算出，和 CAD 模型、干涉檢查、3D 動畫用的是同一套幾何。

1. 為什麼內外輪要轉不同角度Ackermann Condition

  • 車子低速轉彎、輪胎不打滑時，每個輪子都只能沿自己的滾動方向前進，所以四個輪子的輪軸延長線必須交在同一點：轉彎中心 O
  • 後輪不轉向，輪軸固定在後軸線上，所以 O 一定落在後軸線的延長線上
  • 內側前輪離 O 比較近、走比較小的圓，所以要轉得比較多：δi > δo
  • 如果兩輪轉一樣的角度（平行轉向），兩條輪軸線交不到同一點，至少一個輪子會被拖著側滑，輪胎磨損、轉向變重，在玩具車上則是轉不順、抖動

由圖 1 的兩個直角三角形（R 量到後軸中點，K = w/2 是主銷到中線的距離）：

tan δi = L / (R − K) tan δo = L / (R + K) cot δo − cot δi = (R + K)/L − (R − K)/L = w / L = 80 / 160 = 0.50
  • 這就是阿克曼條件：只要知道內輪角，外輪的理想角就定了，和轉彎半徑無關
  • 例：內輪 32.3° 時，理想外輪 = atan(1 / (cot 32.3° + 0.50)) = 25.66°
  • 轉彎半徑：R = L / tan δi + K；內輪 32.3° → R ≈ 293 mm

2. 阿克曼梯形與經驗法則Ackermann Trapezoid

  • 傳統做法：兩個轉向節各伸出一支轉向臂，用一根橫拉桿相連，四根桿件在平面上形成梯形
  • 轉向臂往內斜 β，一側轉向時，內側轉向臂「轉得比較快」，內輪自然轉得比外輪多
  • 經驗法則：兩支轉向臂延長線交在後軸中點，即 tan β = K / L，本車 β = 14.0°
  • 這條法則只在小角度時近似成立，而且是針對「一根橫拉桿」的梯形；本機構是伺服曲柄＋兩支拉桿（分段式），最佳 β 不同，要用解析／數值方法找
  • 本設計的 β = 19°，延長線交在 y = -76 mm，在後軸（y = -120）前方

3. 本機構：伺服曲柄＋兩支拉桿Split Tie-Rod Linkage

  • MG90S 輸出軸在車子中線上，曲柄有兩個銷，在軸前方 27 mm、左右各 8 mm
  • 每一側是一組四連桿（Four-Bar Linkage）：伺服軸→曲柄銷（曲柄）、曲柄銷→轉向臂端（拉桿 26.45 mm）、轉向臂端→主銷（轉向臂 a = 18 mm，內傾 β = 19°）、主銷→伺服軸（車架，固定）
  • 左右兩組共用同一支曲柄，但幾何互為鏡像；曲柄往左轉時，左側四連桿和右側四連桿走在不同區段，這就是內外輪轉角不同的來源

給定伺服角 θ，求輪子轉角 δ 的方法（程式 Linkage.wheel_angle）：

  1. 曲柄銷位置 J(θ) = 旋轉 θ 後的 (±c, j)
  2. 轉向臂端 A 必須同時在「以主銷為圓心、半徑 a」與「以 J 為圓心、半徑 = 拉桿長」的兩個圓上 → 兩圓交點，取靠近直行位置的那一個解
  3. δ = 轉向臂從直行位置轉過的角度；同時算出拉桿與轉向臂的夾角，也就是傳力角（Transmission Angle）μ
|A − Kp| = a （A 在轉向臂圓上） |A − J(θ)| = 拉桿長 （A 在拉桿圓上） δ = ∠(A − Kp) − ∠(A0 − Kp) （A0：直行時的轉向臂端）

4. 結果：和理想阿克曼比較Results

  • 伺服 ±17.5° 就從直行轉到打到底：內輪 32.3°、外輪 25.9°（理想 25.66°）
  • 全行程最大誤差 0.83°，出現在內輪約 22.8°（伺服 13.2°）；外輪略多轉，偏向平行轉向一側
  • 阿克曼百分比（實際內外角差 ÷ 理想內外角差）在打到底時 96 %

5. 尺寸怎麼選出來的Design Search

  • 固定條件：主銷在 (±40, 40)、軸距 160 mm（Technic 8 mm 格的整數倍）、內輪打到底 32°
  • 掃描變數：轉向臂長 a（14～30 mm）、內傾角 β（4～30°）、曲柄銷橫距 c（4、8、12 mm）、曲柄銷前距 j（22～36 mm）
  • 限制條件：曲柄銷整個行程都在伺服座前緣之前（不撞伺服座）、傳力角 ≥ 35°、伺服角 ≤ 45°
  • 目標：全行程最大阿克曼誤差最小 → 選出 a = 18、β = 19°、c = 8、j = 27

6. 實務上要注意的地方Practical Notes

  • 0.8° 的理論誤差比實際誤差小很多：銷孔間隙、伺服齒輪背隙、轉向節晃動通常都超過 1°；理論誤差在這個量級時，阿克曼幾何已經不是限制
  • 阿克曼條件假設低速、輪胎不側滑；車速高時輪胎有滑移角（Slip Angle），賽車常故意用較少的阿克曼，玩具車低速則越接近理想越好
  • 轉向沒有機械擋塊，伺服機要在程式裡限制在 ±17.5°；超過時傳力角繼續變小，可能卡死或讓伺服過載
  • 整車的後輪距（130 mm）和前輪距不同，不影響阿克曼條件：條件只和主銷距 w 與軸距 L 有關
