四連桿：長度限制與運動種類

四根桿長決定了機構能不能組起來、哪一根桿能轉整圈，以及輸入軸轉動時輸出軸怎麼動。本頁從輸入軸與輸出軸的運動關係，把四連桿分成六種，並附可調桿長的互動模擬。

1. 名稱與符號

  • 機架 d（Ground / Frame）：固定不動，兩端是輸入軸 O₂ 與輸出軸 O₄
  • 輸入桿 a（Input / Driver）：接馬達或手柄，轉角 θ
  • 連結桿 b（Coupler）：不接機架，把運動從輸入傳到輸出
  • 輸出桿 c（Output / Follower）：轉角 φ，是我們要的運動
  • 把四根桿長由小到大排成 s ≤ p ≤ q ≤ l：s 最短、l 最長，p、q 是另外兩根
  • 能「轉整圈」的桿稱曲柄（Crank），只能來回擺的稱搖桿（Rocker）

2. 長度限制

  1. 能組成封閉迴路：最長桿必須小於另外三根之和
    l < s + p + q （l = s + p + q 時四根桿拉成一直線，完全不能動）
  2. 葛拉索夫條件（Grashof Condition）：決定有沒有桿能轉整圈
    s + l < p + q → 葛拉索夫機構：至少一根桿能相對其他桿轉整圈 s + l = p + q → 變點機構（Change Point）：能轉整圈，但會經過四桿共線的「攤平」位置 s + l > p + q → 非葛拉索夫：沒有任何一根桿能轉整圈，四根桿都只能擺動
為什麼是 s + l ≤ p + q？以輸入桿 a 要轉整圈為例：
  • 輸入桿轉到和機架重疊（θ = 0°）與拉直（θ = 180°）兩個位置時，O₂、A、O₄ 共線，A 到 O₄ 的距離分別是 |d − a| 與 d + a
  • 這兩個位置都必須能和連結桿、輸出桿組成三角形（含退化）：
    d + a ≤ b + c （拉直時夠得到） |d − a| ≥ |b − c| （重疊時不會太短）
  • 把四種正負號組合整理後，等價於「a 是最短桿，且 s + l ≤ p + q」。同理可推得其他桿轉整圈的條件，所以葛拉索夫條件加上「誰最短」就決定了運動種類

3. 運動種類：看輸入軸與輸出軸怎麼動

葛拉索夫機構中，最短桿放在哪個位置決定種類。下面前四種其實是同一組桿長 2、4、5、4.5，只是固定不同的桿當機架，這稱為運動倒置（Kinematic Inversion）。

條件最短桿位置種類輸入軸 O₂輸出軸 O₄例子
s + l < p + q輸入桿 a曲柄搖桿轉整圈擺動雨刷、縫紉機踏板（反用）、碎石機
s + l < p + q機架 d雙曲柄轉整圈轉整圈（不等速）拖曳連桿、振動篩
s + l < p + q輸出桿 c搖桿曲柄擺動轉整圈腳踏縫紉機、腳踩陀螺
s + l < p + q連結桿 b雙搖桿（葛拉索夫）擺動擺動（連結桿可轉整圈）
s + l = p + q—變點機構轉整圈轉整圈或擺動，經過共線點會分岔平行四邊形連桿、火車動輪
s + l > p + q任何位置三搖桿（非葛拉索夫）擺動擺動阿克曼轉向每一側、汽車懸吊

每張卡片左邊是機構圖（藍色是輸入桿可到達的範圍、橘色是輸出桿的範圍），右邊是輸出角 φ 對輸入角 θ：實線是開口組態（Open），虛線是交叉組態（Crossed）。同一組 θ 可以有兩個 φ，就是四連桿的兩種裝配方式。

4. 輸入與輸出的數學關係

  • 位置：Freudenstein 方程式：把迴路向量 a + b = d + c 的 b 消去，直接得到 θ 與 φ 的關係
K₁ cos φ − K₂ cos θ + K₃ = cos(θ − φ) K₁ = d / a K₂ = d / c K₃ = (a² − b² + c² + d²) / (2ac) 解：A = cos θ − K₁ − K₂ cos θ + K₃ B = −2 sin θ C = K₁ − (K₂ + 1) cos θ + K₃ φ = 2 atan[ (−B ± √(B² − 4AC)) / (2A) ] （取 − 號是開口組態、+ 號是交叉組態）
  • B² − 4AC < 0 時無解：這個 θ 組不起來，輸入桿只能在有解的範圍內擺動；B² − 4AC = 0 是擺動的端點（連結桿和輸出桿共線）
  • 速度比：對 θ 微分得輸出角速度
    ω₄ / ω₂ = a · sin(θ₃ − θ) / [ c · sin(θ₃ − φ) ] （θ₃：連結桿角度）
    雙曲柄的兩軸都轉整圈，但這個比值一直在變，所以是「不等速」傳動
  • 傳力角 μ（Transmission Angle）：連結桿與輸出桿的夾角
    cos μ = [ b² + c² − (a² + d² − 2ad cos θ) ] / (2bc)
    μ 越接近 90° 傳力越好；一般要求 μ ≥ 40°。最小值出現在 θ = 0° 或 180°（輸入桿與機架共線時）
  • 急回比 Q（Quick-Return Ratio，曲柄搖桿）：輸出桿往返兩個極限位置時，曲柄轉過的角度不同
    Q = (180° + α) / (180° − α) α：兩個極限位置的曲柄角差減 180°
    Q > 1 表示回程比去程快，常用在牛頭刨床、送料機構

6. 應用：阿克曼轉向的每一側是三搖桿

  • MG90S 前輪轉向的每一側：機架 = 伺服軸到主銷 56.57、輸入曲柄 28.16、拉桿 26.45、轉向臂 18
  • s + l = 18 + 56.57 = 74.57 > p + q = 26.45 + 28.16 = 54.61 → 非葛拉索夫三搖桿：伺服與輪子都只擺動，正好符合轉向只需 ±17.5° 輸入、±32° 輸出的需求
